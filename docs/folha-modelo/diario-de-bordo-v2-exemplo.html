COMO PREENCHER

  1. Cada linha é um só período: PRODUZINDO ou PARADO. Nunca os dois.
  2. Parou a máquina? Feche a linha (escreva o FIM) e abra uma linha nova de PARADA com o código do motivo.
  3. Voltou a produzir? Abra outra linha de PRODUÇÃO com a mesma peça.
  4. O FIM de uma linha é o INÍCIO da próxima. Não deixe buraco.
  5. Marque ✓ PEÇA TERMINOU só na linha em que a peça ficou pronta (1 ✓ = 1 peça).
  6. Troca de turno: feche a linha e o próximo operador começa outra, com a chapa dele.

CÓDIGOS DE PARADA (coluna MOTIVO)

  • 1Mecânica
  • 2Elétrica
  • 3Preventiva
  • 4Aguardando peça
  • 5Falta de peça
  • 6Ponte rolante
  • 7Troca de consumíveis
  • 8Troca de peça
  • 9Set-up
  • 10Outros (descreva)
Na falta de peça (5), o contramestre escreve na observação para qual atividade ou área o operador foi.

Certo: 2,5 h produzindo + 1 h parado = 4 h.  Errado: uma linha 13:00–17:00 e a parada à parte (a hora parada conta duas vezes).
